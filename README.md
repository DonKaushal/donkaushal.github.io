# Kaushal Ranasinghe — Portfolio Website

A responsive, accessible, dark/light-switchable portfolio built with **HTML, CSS and vanilla JavaScript**.

## Preview locally

Open `index.html` in your browser, or use the **Live Server** extension in VS Code.

## Publish with GitHub Pages

1. Back up any existing files in your `DonKaushal/donkaushal.github.io` repository.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder to the repository root (not inside another folder).
3. Commit the files to the `main` branch.
4. Open **Settings → Pages → Build and deployment**.
5. Choose **Deploy from a branch**, branch **main**, folder **/(root)**, then **Save**.
6. Once GitHub Pages reports a successful deployment, visit `https://donkaushal.github.io/`.

## Customize

- Edit `index.html` to update project descriptions, education, and contact details.
- Edit `style.css` for typography, colors, and layout.
- Edit `script.js` for theme-switcher and mobile menu behavior.
- Project links point to existing public repositories, but descriptions should be checked against their actual content.
- No personal email or CV is included because neither was provided for publication.
- The site uses Google Fonts; if offline, system fonts will be used.

## Safety

Do not commit `.env` files, credentials, API keys, private customer data, or confidential employer code.
